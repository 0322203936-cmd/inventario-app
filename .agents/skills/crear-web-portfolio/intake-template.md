# Intake — the few things only the person can give you

A portfolio is about a real person, so the intake gathers **their truth** (which
you can't invent) and nothing about design (which you decide). Ask in ONE
message, keep it short, offer defaults.

## First, route (don't ask yet)

Connect, publish, upgrade and edit asks need little or no intake. Reserve the
questions for a fresh **build**.

## For a build — ask at most these, once

1. **Who + what field** — their name and what they do (illustrator, developer,
   musician, photographer, writer, or a career/personal brand). This picks the
   niche (`02-portfolio-niches.md`). Infer if obvious.
2. **The work** — their pieces/projects/tracks/clips/milestones, with real
   titles, years and links. «Pásame lo que quieras enseñar» — the more concrete,
   the better. Fewer strong items beat many weak ones.
3. **Images / files** — «sube tus imágenes/obras a `{proyecto}/assets/photos/
   source/`, o dime que use marcadores de posición y los cambias luego».
4. **Goal** — what should a visitor do: contratarte / encargarte algo /
   contactarte / descargar tu CV / escucharte en Spotify. Sets the CTA.
5. **Optional — public audience.** If they're a creator with a real channel/feed
   (YouTube, podcast, GitHub…), ask for the handle / channel id / feed URL so you
   can wire a live-proof module (`16-creator-live-modules.md`): a real subscriber
   count, a rolling counter, a "latest content" carousel. Skip it entirely if
   there's no real public audience — never fabricate the numbers (invariant 1).

Template (Spanish — translate to the user's language):

> Para montarlo necesito lo tuyo (el diseño lo decido yo):
> 1. **Tu nombre y a qué te dedicas** (dibujo, desarrollo web, música,
>    fotografía, tu trayectoria…).
> 2. **Qué quieres enseñar**: tus obras / proyectos / temas / hitos, con título,
>    año y enlace si lo tienen. Mejor pocas cosas buenas que muchas flojas.
> 3. **Imágenes**: súbelas a la carpeta de fotos cuando la cree, o te pongo
>    ejemplos y los cambias después.
> 4. **Objetivo**: ¿qué quieres que haga quien entre? (contratarte, encargarte
>    algo, contactarte, descargar tu CV, escucharte…).

## Never ask

Palette, fonts, layout, which archetype, which effects, mobile approach, any
tech decision — you decide all of it from the niche.

## The one thing to SAY, not ask

You'll never invent achievements: whatever they don't give you becomes a clear
placeholder to swap, never a made-up claim (invariant 1). Say it once so they
know the page is honestly theirs.

## After they reply

Acknowledge in one line, then build. Gaps → defaults: no images → tasteful niche
placeholders; goal unclear → "contactar"; one page unless the work needs
several. Tell them when it's ready and how to swap in their real files. Don't
narrate every step.
