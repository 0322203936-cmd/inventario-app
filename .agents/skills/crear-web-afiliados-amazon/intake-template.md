# Intake — the few things worth asking

Most builds need one or two answers. The niche decides the schema; everything
else you infer.

## First, route (don't ask yet)

Connect, populate, publish, edit and verify asks need **no** intake. Reserve
questions for a fresh **build**.

## For a build — ask at most these, once

1. **Niche** — what products (bicis eléctricas, monitores, robots aspiradores,
   cafeteras…). If they named it, skip. If not, offer 2-3 good affiliate niches
   (`02` §Recommend) — don't recite a list.
2. **Amazon marketplace** — which country's Amazon (`.es`, `.com`, `.it`…), for
   currency and the affiliate program. Default `.es` / EUR unless the links say
   otherwise.
3. **Self-service?** — «¿querrás añadir productos tú desde un panel, o me pasas
   los enlaces y los añado yo?» Decides JSON vs PHP+SQLite (`03`). Default: you
   add them (JSON).
4. *(don't ask — say it)* You'll ship the site with 2-3 sample products so they
   see it working, then fill it for real when they paste their affiliate links.

Template (Spanish — translate to the user's language):

> Para montarla necesito un par de cosas:
> 1. **¿Qué productos?** (bicis eléctricas, monitores, cafeteras… el nicho).
> 2. **¿Qué Amazon?** (España, México…), para la moneda y tu programa de
>    afiliados.
>
> El diseño, la estructura y las fichas los decido yo. La lleno con productos
> cuando me pases tus enlaces de afiliado — de momento la dejo con un par de
> ejemplos para que veas cómo queda.

## Never ask

Palette, fonts, layout, which chart, JSON vs SQLite internals, the schema
fields — you design those. If they volunteer a preference, honor it.

## The one thing to SAY every time

Populate happens from **their own affiliate links**, and their tag is preserved
exactly — so the site earns for them, not for anyone else. Mention it once when
you hand over the empty site.

## After they reply

Acknowledge in one line, then build the structure + sample products. Tell them
it's ready and how to fill it («pásame tus enlaces de afiliado, uno por línea»).
Don't narrate every step.
